POWER STRENGTH GYM — ANDROID APP

WHAT'S INCLUDED
- Member register (name, phone, plan, fee, start date, payment status)
- Fee tracking and pending-fee WhatsApp reminder links
- Daily attendance by date
- Expense tracking
- Dashboard totals
- JSON backup and restore
- IndexedDB browser storage; data remains on this device/browser between normal visits

IMPORTANT LIMITATIONS
- WhatsApp reminders open WhatsApp with a pre-filled message. The gym owner must review and press Send. This app does not send automatically.
- Data is stored locally in the browser, not in a cloud database. It does not sync between devices or users.
- Browser data can be lost if site data is cleared, the browser profile is removed, or the device is lost. Use Backup regularly.
- This starter app is not a native APK and has no login, staff accounts, automated billing, or cloud backup.

DEPLOY FOR ANDROID (FREE OPTION)
1. Extract this ZIP on a computer.
2. Create a free GitHub account and a new public repository, e.g. power-strength-gym.
3. Upload index.html, manifest.json, and sw.js to the repository root.
4. In repository Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
5. Wait for GitHub Pages to publish the site. Open the published HTTPS address on your Android phone using Chrome.
6. Chrome menu (three dots) > Add to Home screen / Install app. The icon will appear on the home screen.
7. Add a test member and export a backup before entering all your real records.

ALTERNATIVE HOSTING
You can deploy the three files to a free static HTTPS host such as Netlify Drop. Use the HTTPS site address on Android Chrome and choose Add to Home screen.

DATA SAFETY
- Export a backup at least weekly and before changing phones.
- Keep backup files private because they contain member personal information.
- Ask members for permission before sending WhatsApp reminders.
- For multi-device access, staff logins, secure cloud database and automatic backup, a backend service and a more complete app build are required.
